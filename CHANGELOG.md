# Changelog

## [0.1.0] - 2024-08-06

### Added
- Initial release of Drag & Drop AI Excel App for Windows
- Drag and drop file upload interface
- Support for multiple file formats:
  - Text files (.txt)
  - CSV files (.csv)
  - Images (.png, .jpg, .jpeg, .gif) with OCR
  - URLs with web scraping
- Automatic data processing and formatting
- Excel file generation with:
  - Custom formatting
  - Auto-adjusted columns
  - Border styling
  - Optional chart generation
- Data merging capability for multiple files
- Real-time data preview
- Windows native UI integration
- Error handling and user feedback
- Complete documentation

### Features
- ✨ Intuitive React-based UI
- 🎯 Electron desktop application
- 🔄 Python Flask backend
- 📊 openpyxl Excel generation
- 🖥️ Windows 10/11 compatible
- 📦 Portable and installer versions

### System Requirements
- Windows 10 or later
- 4GB RAM minimum (8GB recommended)
- 500MB disk space
- .NET Framework (included in Windows 10+)

### Known Issues
- Image OCR requires Tesseract installation for full functionality
- Large files (>50MB) may take longer to process
- Chart generation is limited to bar charts in this version

- [ ] PDF support

## Installation & Upgrade

### From v0.0.0 to v0.1.0
- Fresh installation required
- No migration needed

### Portable Version
- Download: `Drag & Drop AI Excel App-portable.exe`
- No installation needed
- File size: ~300-400MB
- Extract and run

### Installer Version
- Download: `Drag & Drop AI Excel App Setup 0.1.0.exe`
- Run installer wizard
- Install size: ~500MB
- Automatic Start Menu shortcuts
